# Piedrazul – Appointment Scheduling System

This repository contains the source code for the **Piedrazul appointment scheduling system**, developed as part of the **Software Engineering III course** at Universidad del Cauca.

The system is composed of a backend API, a frontend web application, and infrastructure configuration for local development.

---

## Project Structure

```
piedrazul-agendamiento-citas
│
├── backend        # Spring Boot REST API
├── frontend       # Angular application
├── infra
│   └── compose    # Docker Compose configuration
│       └── db.yml
│
├── .env
├── .env.example
└── README.md
```
